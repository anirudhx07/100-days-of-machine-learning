
# 🚀 100 Days of Machine Learning

A structured 100-day journey to learn, implement,
experiment and understand Machine Learning.

**Timeline:** 04 August 2026 – 11 November 2026

## 🎯 About This Repository

This repository documents a structured learning
journey covering Python, Mathematics, Data Science,
Machine Learning and Deep Learning.

Each learning day contains:
- Concept explanations
- Python implementations
- Jupyter experiments
- Personal learning notes
- Practical exercises

## 📚 Learning Roadmap

| Phase | Topic | Days |
|---|---|---|
| 01 | Python Foundations | 01–10 |

| 03 | Python for Data Science | 21–30 |
| 04 | Data Visualization | 31–40 |

| 06 | Supervised ML | 51–60 |

```text

```

## 📈 Learning Principles

1. Understand before implementing.
2. Write code independently.
3. Experiment with real datasets.
4. Evaluate model performance.
5. Document every meaningful experiment.
